# Swastika Lodge & Cafe Website

## Build
- Create a shared responsive header, mobile menu, footer, booking strip, WhatsApp links, call links, and directions links.
- Build separate Home, Rooms, Cafe, Amenities, About, Gallery, Location, and Contact pages.
- Use all ten supplied photographs through direct source imports, with no image JSON, remote imagery, placeholders, or generated assets.
- Apply a warm Himalayan boutique-lodge design with editorial typography, generous whitespace, restrained motion, and accessible controls.

## Page content
- Home: photographic intro, location/rating highlights, amenities, room and cafe previews, experiences, and booking prompt.
- Rooms: Standard, Deluxe, and Super Deluxe details with the supplied room photography and WhatsApp enquiry links.
- Cafe: breakfast, lunch, dinner, customizable meals, and Beas River setting without inventing menu items.
- Amenities: only the listed facilities, plus a separate experiences area for Spiti, Leh-Ladakh, and Atal Tunnel rides.
- Gallery: masonry layout using all supplied images, smooth image treatment, and keyboard-accessible fullscreen viewing.
- Location: exact address, nearby landmarks, directions action, and the exact supplied Google Maps embed.
- Contact: WhatsApp booking, phone, address, check-in/out, and the supplied guest and pet policies.

## Technical details
- Add unique SEO metadata to every page and Hotel/LocalBusiness structured data where relevant.
- Use semantic Tailwind design tokens and direct TypeScript image imports from `src/assets`.
- Ensure mobile and desktop layouts, accessible navigation, reduced-motion support, and lazy loading below the first view.
- Verify the live preview at desktop and mobile sizes, all page links, WhatsApp message links, lightbox behavior, and the map.
